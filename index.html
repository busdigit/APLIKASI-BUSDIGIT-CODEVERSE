Animista — On-Demand CSS Animations Library

Animista adalah library animasi CSS berbasis web yang menyediakan kumpulan animasi siap pakai dan dapat dikustomisasi langsung melalui playground interaktif. Dengan Animista, developer bisa memilih jenis animasi, mencoba preview secara langsung, mengatur opsi animasi, lalu menyalin kode CSS yang dibutuhkan saja tanpa harus menulis keyframes dari awal.

🎯 Kegunaan Utama

Berguna untuk developer dan designer yang ingin menambahkan animasi CSS ke website secara cepat, ringan, dan praktis. Pengguna dapat memilih animasi dari kategori basic, entrances, exits, text, attention, dan background dengan kustomisasi duration, timing-function, delay, iteration-count, direction, dan fill-mode.

👥 Cocok Untuk

  • Frontend Developer & UI/UX Designer
  • Web Designer & Creative Developer
  • Landing Page & Portfolio Developer
  • Pembuat animasi tanpa beban library berat
  • Pemula yang belajar CSS animation & keyframes

⚡ 8 Fitur Utama Animista

1. Koleksi animasi CSS siap pakai.
2. Playground interaktif live preview.
3. Kategori: basic, entrances, exits, text, attention, bg.
4. Kustomisasi duration, delay, timing, iteration.
5. Generate kode CSS animasi otomatis.
6. Salin class & keyframes secara langsung.
7. Cocok untuk micro-interaction & motion FX.
8. Sangat ringan (hanya mengambil CSS yang dipakai).
Tech Stack & Fokus:
CSS Animation CSS Keyframes UI Motion Micro Interaction Text & Background Animation
